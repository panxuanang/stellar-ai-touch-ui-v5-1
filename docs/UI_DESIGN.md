# UI_DESIGN — Touch UI V5.1

## 设计目标

Touch UI V5.1 的目标不是让四块功能区非常“硬卡片化”，而是：

- 在 3.5 寸 480×320 横屏上保持可读性
- 视觉上更像一整个完整界面
- 功能区有边界，但边界尽量柔和
- 中央人物和背景始终是整体画面的一部分

## 首页设计原则

- **中央人物是主视觉**
- 背景保持浅色、柔和、统一
- 左上：时间日期
- 左下：AI 助手状态与开始对话按钮
- 右上：天气
- 右下：今日待办
- 功能区使用淡边框、浅阴影、半透明浅底
- 避免过厚边框和过深投影造成割裂感

## 对话页设计原则

- 保持浅色、安静的阅读界面
- 长文字优先保证可读性
- 页面元素尽量少，避免挤占字幕区域
- 长回答时放大左侧文本区，右侧人物缩小
